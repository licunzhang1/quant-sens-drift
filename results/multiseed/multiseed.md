## How to read this table

1. **The Fisher combined p** is the primary metric. A single seed has very low power at n=10~16 layers,
   so if pooling several independent seeds reaches p < 0.05, the effect is real and
   one run was simply not enough to detect it.
2. **The sign consistency of the cost of domain ignorance** is more robust than rho: see the 'positive seeds' column.
   If every seed is positive, the direction of the conclusion holds up;
   the standard deviation tells you how uncertain the magnitude is.
3. The **rho range** column tells you about stability: if [min, max] crosses 0,
   the sign of rho itself is unreliable, and rho should not be used to carry a conclusion.
